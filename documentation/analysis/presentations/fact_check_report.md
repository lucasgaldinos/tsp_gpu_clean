## 4. Citation Accuracy Issues

### 4.1 Shapiro-Wilk attributed to Demšar — INCORRECT

The statistical protocol slide says:

> **Metodologia** `[@demsar2006statistical]`
>
> 1. **Normalidade:** Shapiro-Wilk

Demšar (2006) does **not** mention Shapiro-Wilk anywhere in the paper (0 occurrences confirmed via text extraction). Demšar discusses normality testing in general terms but recommends non-parametric tests precisely to avoid the normality assumption.

**Fix:** Cite `@shapiro1965analysis` (which IS in refs.bib) for the Shapiro-Wilk test specifically. The overall methodology framework can still be attributed to Demšar, but Shapiro-Wilk needs its own citation.

### 4.2 Cohen's d attributed to Demšar — INCORRECT

The presentation says:

> **Tamanho de efeito:** $d$ de Cohen

in the context of Demšar's methodology. Demšar (2006) mentions Cohen only twice, in the context of criticizing over-reliance on statistical significance — it does NOT recommend Cohen's d for effect sizes.

**Fix:** Cite `@cohen1988statistical` (which IS in refs.bib) for the Cohen's d measure.

### 4.3 Tournament Selection attributed to Larrañaga — NOT FOUND

The parameter table cites:

> Seleção | Torneio | `@goldberg1989genetic`

This is correct — Goldberg is the standard reference for tournament selection. However, in the draft (Section 3.2.1), tournament selection is described alongside other operators that cite Larrañaga. Larrañaga (1999) has **zero mentions** of "tournament" (confirmed via text extraction). The Goldberg 1989 book PDF is not in the collection so cannot be directly verified, but this is a well-established attribution.

## 7. Structural / Minor Issues

1. **Transfer table (slide "Padrão de Transferência por Variante"):** Claims "aprox. 2.560 kernel launches/gen" for Naive. This is 256 individuals × 10 2-opt iterations = 2560, which is correct for $n_{pop} = 2 \times 128 = 256$. However, for berlin52 ($n=52$), $n_{pop} = 2 \times 52 = 104$, so launches would be ~1040, not 2560. The note says "aprox." but the value is specific to a particular instance size. Consider noting this.

2. **Speedup "5.54×":** The presentation says HybridOptimized is 5.54× faster than HybridNaive. Recomputed from `tmp/stats_output/tables/chapter4_validation.md` (39 HybridOptimized rows vs HybridNaive baseline):

   | Metric | Value |
   |:-------|------:|
   | Ratio of aggregate means (47.08 / 18.94) | **2.49×** |
   | Median of per-instance speedup ratios | **5.69×** |
   | Mean of per-instance speedup ratios | **5.38×** |
   | Min / Max per-instance | 1.86× / 6.66× |

   The presentation's 5.54× is close to the per-instance median (5.69×) but slightly understated. The ratio-of-means (2.49×) is not the right metric for this claim; the per-instance median is the correct one. **The 5.54× claim should be corrected to 5.69× (median) or 5.38× (mean)** depending on which statistic is used in the thesis.

3. **"Ressalva importante" on slide "Comparação com a Literatura":** The presentation correctly notes that implementation maturity could affect comparisons. This is a good caveat.

4. **Limitation about 2-opt and directed graphs:** The slide says "2-opt funciona apenas para grafos não orientados (simétricos)" and recommends 3-opt for directed graphs. This is correct — 2-opt reverses a sub-route, which changes direction in asymmetric TSP.

## Summary of Findings

### CRITICAL (Must Fix Before Defense)

1. **Per-instance numerical data** (berlin52, kroA100, pr1002) does not match any checkpoint data. Source is unknown; numbers appear fabricated or from unrecorded runs. *All V2 Actual values in this report are backed by `tmp/stats_output/` (recomputed 2026-04-30).*
2. **pr1002 gap values** are ~4× understated compared to actual data (V2: HybridNaive 8.04%, HybridOptimized 7.77%, FullGPU 4.14%).
3. **"30 repetitions" claim** — actual V2 data has **26 repetitions** per (algorithm, instance) pair.
4. **"0.00% gap for small instances"** claim is false — FullGPU actual mean gap is **0.26%** (n<100, 6 problems) or **0.23%** (n≤100, 12 problems).

### IMPORTANT (Should Fix)

1. **Shapiro-Wilk** and **Cohen's d** need their own citations, not just Demšar. Use `@shapiro1965analysis` and `@cohen1988statistical` respectively.
2. Category gap values: small-instance gap is 0.26%/0.23% (not 0.00%); large-instance gap is 2.76% (not 1.85%). Medium is actually *better* than claimed (0.50% vs 0.65%).
3. **Speedup "5.54×" needs correction** — per-instance median from recomputed data is **5.69×** (mean 5.38×). The ratio of aggregate means is only 2.49×, which is a different and misleading metric.

### MINOR (Nice to Fix)

1. Kernel launch count "2560" is instance-size-dependent (correct only when $n_{pop} = 256$, i.e. $n = 128$ cities).
2. Goldberg 1989 PDF not in collection (but citation is standard and widely accepted).
3. `eiben2011parameters.pdf` does not mention "swap mutation" — the citation should be for `eiben2015introduction` (the textbook, not the 2011 paper).
